Ownership & recovery — how this works without a seed

Names are owned by a tiny cryptographic key (same as every PiNS app — this is protocol, not preference). We create it for you, in this tab, the moment you sign. It cannot spend your PIVX — it only owns names. It lives in this browser and was downloaded as a file when you signed. If you ever switch computers: bring the file, open Manage, Import. If you clear browser data without the file, the name still resolves but can no longer be re-pointed or sold — so keep the download.

How this is safe: static page — nothing here can phone home with a key, the CSP in the page source blocks every domain except the two official PiNS APIs, and all crypto runs in your tab. There is no seed-phrase input anywhere, and no wallet key is ever requested. Verify it: view-source, or ask any AI to audit app.js.
